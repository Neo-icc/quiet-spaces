# 城市山隐｜产品宪法

## 一句话定位
一个晚上十一点还开着的、没有任何人可以跟你说一句话的山谷。你坐下，山就安静三分钟。

## 用户
主线：22–35 岁高压城市白领，23:00–01:00 手机访问。副线：自由职业者、备考者、失眠者、独居者。不面向交友、占卜、冥想课程用户。

## 产品承诺
允许什么都不做；感到有人同场而无需回应；回访时原来的位置、灯和树仍在。

## 核心路径
打开雾谷 → 坐下 → 拨水/扫叶/点灯 → 安静停留 → 起身种树 → 次日回访。

## 不做清单
不做聊天、头像、昵称、私信、打卡、积分、预测、宗教仪式、医疗承诺和主场景付费弹窗。

## 合规红线
无宗教造像、经文、法器、香炉和宗教建筑；无占卜、祈福、许愿；不宣称治疗或改善睡眠；模拟在线人数必须清楚标记为演示数据，不可冒充真人在线。

## 视觉原则
夜雾墨 #0E1416、苔绿 #3F5B4E、石青 #6C8480、灯火暖 #E8B27D（画面占比≤5%）。中文宋体；直角或2px圆角；慢淡入、慢位移；不用玻璃拟态、紫蓝渐变、弹跳动画。

## 技术原则
React + TypeScript + Vite；移动端优先；Canvas 2D；Web Audio API 合成声音；本地持久化；可离线进入；优先静态部署。未实际测试的性能、离线能力和部署不可宣称已通过。
