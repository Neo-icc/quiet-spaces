## 来源和结果

从 ChatGPT 资料空间下载并读取原始任务提示词及 `three-projects-github-pages-verified-v9.zip`。v9 内含三个站点的 HTML、CSS、JavaScript 源码、静态资源及四份模拟或静态检查脚本。原始需求指定的 React/TypeScript/Vite 工程未随 v9 提供。本次以 v9 静态版为提交和验收对象，构建验证检查可直接发布的 `site/`。

| 范围 | 已获得的证据 | 仍待验收 |
| --- | --- | --- |

| 公开发布 | 静态构建与浏览器检查已在 GitHub Actions 通过。仓库已公开，Pages 已启用 | 部署结果和公网复测以 Actions 运行与实际站点为准 |

使用的命令为 `npm test` 和 `npm run test:browser`。后者运行真实浏览器引擎，移动部分用桌面浏览器模拟屏幕和触摸。计时采用浏览器虚拟时钟，麦克风使用浏览器模拟设备。原始需求的完整产品终审仍有缺项。

## 已修复

- 山隐允许本地安全上下文注册 Service Worker，离线回退限定在自身缓存，扫叶反馈会自动清理，起身时清除已停止的计时显示。
- 壁炉防止重复请求麦克风，并在离开后释放迟到的音轨。音景结束逐渐淡出，断开不再使用的节点，呼吸相位采用四态各自的吸气与呼气时长。
- 嵌套路径的 404 入口可以回到项目站点根目录。

## P2 硬件

本次运行的是情绪壁炉网页。实体原型、传感器、固件、蓝牙通信和结构打样均未实测。v9 未包含硬件 BOM 或 GATT 协议草案。
